# UI-3 编辑骨架与属性 · 交付记录

日期：2026-09-30。状态：实现与针对性功能检查完成，等待用户视觉验收。UI-2 已获用户明确通过。本批不进入 UI-4/5/6 或 B7/B8。

## 本批交付

- 五个档案纸签：基本资料、基础属性、职业与技能、背景故事、武器与物品。桌面左侧，手机横向滚动；切换只改变显示，输入节点保留。方向键和 Home/End 可切换，ARIA 选择状态和焦点同步。
- 基本资料采用姓名印章、黑玫瑰和干净纸面。保留姓名、年龄、性别、时代、住地、故乡及原年龄规则提示。
- 中文八维属性牌：力量、体质、体型、敏捷、外貌、智力、意志、教育。桌面四列两行，手机两列；幸运独立一行。派生值继续由既有 preview API 计算，初始理智独立填写。
- 天命弹窗以档案袋方案呈现。继续调用原 `/api/characteristics/rolls`，数量范围、骰点方法、幸运、总值及初始理智规则未改。未采用的骰点不修改卡片；采用后立即标记未保存。
- 购点设置确认后展示分配进度、已用/总额/剩余及是否包含幸运。超点显示暗红和负剩余，结束购点隐藏面板。沿用既有规则；购点设置仍是本次编辑的工作状态，不新增持久字段。
- 固定保存栏：桌面右上，手机屏幕底部。包括尚未保存、未保存修改、保存中、已保存、失败。只有 HTTP 保存成功才认定保存。编辑页保存不刷新，保留当前分区和输入；新卡保存后更新 URL 和操作入口，后续保存使用 PATCH，不重复创建。
- 保存状态比较实际卡片数据，不把切换分区、技能视图或打开弹窗算作修改。程序填入天命、技能变化等同样检查。保存请求期间再次输入的内容保留，成功后仍显示未保存。
- 服务器拒绝、网络中断、预览失败、会话过期都保留输入并报告真实错误；在保存中阻止重复提交。不同预览响应通过序号和数据快照防止旧响应覆盖新输入。
- 未保存时，站内导航及退出/复制/删除前提醒；刷新/关闭使用 beforeunload。取消删除不会解除离开提醒。原生离开提示文字由浏览器决定。

## 修改位置

- `web/pages.js`：编辑 HTML、属性及派生值结构、纸签和弹窗。
- `web/site.css`：替换原编辑页样式，不保留旧列表样式路径。
- `web/editor.js`：预览、天命/购点呈现、保存、键盘切换。
- `web/editor-state.js`：数据快照、保存反馈及离开提醒；作为本站编辑脚本的一部分内联，不新增静态公共路由。
- `web/card-actions.js`：操作成功导航通知，避免丢失未保存修改提醒。

沿用现有 Node HTML + 原生 JS/CSS；没有新增依赖、生成美术资产、改制卡公式、改 auth/storage 或真实角色库数据。职业技能与装备保留可用控件，专门设计留给 UI-4/5。
