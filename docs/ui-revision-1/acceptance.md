# 第一轮统一修改

状态：按用户 A/B/C/D 清单完成，等待实际视觉反馈；不是整站最终验收。

## 内容

- 携带物品及法术各用一个宽文本框。没有新增/删除逐条按钮，也不显示现金栏。已有现金值在保存时保留，避免打开旧卡后丢失数据。
- 武器和物品下面为“更多调查员信息”，默认收起；里面法术、个人资产、神话、调查员经历、调查员伙伴分别采用第二级折叠面板，默认收起。
- 调查员经历使用已有 personalHistory 字段并从背景区移入更多信息；个人资产 assets、神话 mythos、伙伴 companions 使用背景中的可选文本字段，保存、导出、导入均支持。
- 伤疤改名“伤口伤疤”。
- 隐藏职业编号，只保留 ID 作为目录选择及规则所需数据。取消重复职业技能编辑列表；本职不提供删除，目录说明含任选要求时提供任选技能入口。自定义职业保留公式及信用范围编辑。
- 兴趣页只列玩家选入或已有兴趣配点/非本职成长的技能，不列全默认表。兴趣可选择及移除；选入但零配点用 interestSelected 布尔值持久保存。移除同时是本职的兴趣选择只清除兴趣配点与选择，不删除本职技能。
- 技能排版改为名称与成功率一行，配点控件紧接其下，资料编辑按需展开。删除只保留一个入口，本职隐藏。没有采用参考示意中的新技能上限规则。
- 保存状态及修改按钮位于表单后方，正常文档流占位、底部居中，不悬浮覆盖字段；编辑页导出、复制、删除入口移除，继续在我的调查员页面操作。
- 性别改为男/女选择。
- 侧栏更换新生成的摊开书本、羽毛笔、烛台；头像占位去掉旧黑玫瑰叠图，使用重新生成的平面藤蔓花饰框。用户拒绝的立体金属框没有接入。
