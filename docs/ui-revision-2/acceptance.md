# 第二轮技能与保存按钮修订

按用户六项反馈修改：不可计算点数显示“无”；删除技能资料展开编辑；技艺、科学、格斗、射击直接展示完整专攻下拉框，可以反复重新选择；信用评级第一；成功率明确显示百分比和困难、极难值；保存区只保留红色按钮，取消修改监控、状态标记和离开提醒。请求期间按钮暂时显示正在保存，失败仍显示真实错误。

沿用规则：regular = base + growth + occupationPoints + interestPoints，困难为向下取整的一半，极难为向下取整的五分之一。每加 1 点增加 1 个百分点，没有引入每点加 5% 的规则。规则证据：rules/coc7.js 的 skillRating、hardSuccess、extremeSuccess。

75 项自动测试通过。真实 Edge + 临时 SQLite + 模拟会话：1440/1280/390/320 的专攻反复选择及保存、70%/35/14 实时计算、信用首位、单个保存按钮、无横向溢出通过。结果及截图在本目录。未操作实际用户卡，真实 OAuth 本轮未实测，视觉效果待用户确认。

用户澄清按钮一次操作应分配5点：技能加减按钮已改为±5，手填仍支持整数，减法最低0。截图属性及占卜师公式核对：55×2＋max(55×2,40×2)=220；兴趣70×2=140。总额与规则保持原有计算，不乘5。
保存按钮补修：不再因为预览校验错误而禁用；仅提交请求期间禁用。点击时展示具体校验原因，非法数据仍不能写入。浏览器验证信用评级错误可点击、显示原因、按钮恢复、旧数据未被改变。
