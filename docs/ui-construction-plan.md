## 2. 已定设计

- 风格：私人调查员档案馆，丰富旧纸细节、酒红纸签、铜色角饰、姓名印章、蜡封和克制的神秘纹样。不能简化成普通米色表单。
- 登录页尽量保留暖灯、书籍、地图、旧照片、怀表与书桌景深；现有无字背景优先使用，真实标题和按钮叠加其上。
- 中文为主：主标题“茶话会调查员档案馆”，英文馆名作小字；八维、幸运、派生值和职业公式使用中文。
- 配色：背景 `#EDE8DD`、纸面 `#F7F4EC`、正文 `#282724`、次文字 `#777066`、酒红 `#6B2D35`、铜金 `#8C7048`；成功用墨绿，错误用暗红。
- 保留装饰数量与精致度；通过正文区域低纹理、清晰字号和足够间距提高舒适度。装饰不得遮挡输入、点击或焦点。
- 标题使用有档案气质的中文衬线字体，正文和数字优先易读；字体文件附许可，不照搬十二国记的书法标题字体。
- 档案卡用姓名首字印章占位，不添加假定永久有效的 CASE 编号。提供编辑、导出与更多操作。
- 桌面八维四列两行，幸运独立；手机两列。编辑页五个档案标签每次显示一个分区，手机标签横向滚动。
- 天命使用独立档案袋弹窗，支持原有 X 组方案；购点开启后再展示面板。初始理智独立可填。
- 技能用紧凑行式与搜索，保留本职/兴趣、混点、成长和专攻规则。成功率显示“普通 · 困难 · 极难”，手机也能查看说明。
- 职业采用可搜索选择器，以职业 ID 区分同名项，展示信用范围、中文公式与技能摘要；保留自定义编辑能力。
- 背景像手记，使用宽文本框。武器使用文字军械目录，不放武器图片；主要数据直接显示，其余资料可展开编辑。
- 固定“保存状态＋保存修改”，首版手动保存，支持未保存、已修改、保存中、已保存、失败，以及离开提醒。

## 3. 资产方式

资产生成通用总则（2026-09-30 补充）：禁止鱼鳞纹、噪点及无端增加过多细节。保留视觉基准中的有意义装饰，不叠加无关纹样造成视觉疲劳；纸面用柔和色阶，不使用颗粒噪声。

资产目录：`D:\git项目\TeaParty-Bell\CoC-Character-Card\web\assets`。所有美术素材放在本项目内，不使用外部仓库工作目录。

已存在：`web/assets/登录页背景-v1.png`，从原外部目录移动而来，内容保持不变。后续按需增加素材说明、生成提示词及独立试装页，新增文件使用明确的 kebab-case 名称。

参考十二国记生成器的资产方法：独立绘制无字素材，透明边饰与章记保留透明通道；边框用 CSS 九宫格切片/固定角饰适应不同尺寸；标题、数值、输入框和按钮均为真实 HTML。禁止将整张参考图铺成可操作页面。

首批素材按实际需要制作：馆徽、浅纸纹、档案卡边框、页角铜饰/植物边饰、分隔纹、空白姓名印章、蜡封、米白与酒红纸签。普通按钮、字段和进度条优先 CSS，不为每个控件生成图片。

每件素材记录来源、用途、尺寸、透明性、提示词或许可；保留原始图，另产运行用压缩版本。设置资产试装页，检查米色底上的透明边缘和窄屏裁切。

运行资产随 CoC-Character-Card 部署，由本站提供明确的静态路由。`web/assets/` 保存选定的运行文件，原始大图与试装记录按需放在该目录的子目录中，不对外暴露无关文件。十二国记的 GitHub raw 发布方式可作为日后外链发布参考，本轮不上传或发布。

## 5. 实现原则与验收

沿用当前 Node 服务端 HTML＋原生 JS/CSS，复用现有目录、规则预览与角色 API，不引入前端框架。视觉、交互、规则各自负责自己的部分；按实际复杂度拆文件，不预建组件体系，不保留被替换的旧 UI 路径。

视觉验收使用 1440px、1280px、390px、320px 宽度；登录背景裁切保持主体，列表和编辑无整页横向溢出。正文以 16px 左右为基准，触摸目标尽量至少 44px；检查焦点、标签、弹窗键盘行为和对比度。

各代码批次运行 `npm test`，对新增交互补必要验证；浏览器实际检查素材/字体加载、控制台、布局及相关操作。模拟登录或临时测试库的验证单独标注，不能称为真实 Discord OAuth 验收。测试不接触生产数据库。

最终检查：新建、编辑、复制、删除、导入、导出、天命、购点、技能点分配、护甲与装备均可用；长姓名、长背景、重复职业名、无搜索结果、超点、保存失败及会话到期提示可理解。

真实 OAuth、身份资格、生产 Cookie 和小 G 宝对接未验证时明确标为待验；静态截图不替代功能验收。参考图中的示例数字与文字不作为规则依据。
