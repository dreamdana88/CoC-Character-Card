## 2026-09-30 四项定向修订

1. 信件照片的直切边来自生成原图，不是 CSS 容器裁切。使用内置 imagegen 精确编辑补全左侧，替换原图和 WebP，透明轮廓完整。
2. 桌面卡片统一 288px；中屏单列 264px；手机两列属性布局统一 348px。长姓名和职业单行省略，姓名/职业 title 保留完整信息，编辑页正常显示全文。绝对定位装饰不参与卡片高度计算。
3. 植物照片旧文件 600px 宽，而有效内容约 285px 宽，导致同尺寸容器实际显示过小；按 alpha 有效边界去掉空区。侧饰采用固定高度居中而不跟随卡片拉伸。桌面有效高度约 236–244px，手机约 167–174px；各屏五种装饰有效高度最大/最小比小于 1.08。
4. 操作区通过列布局统一贴近底部，底部纸面余量至少 14px，白露不再跟随长姓名卡拉高。

新增浏览器定向断言：所有五卡高度一致、操作区底部余量、侧饰有效高度比例；四种屏宽均通过。详细实测在 layout-1440.json、layout-1280.json、layout-390.json、layout-320.json。npm test 74/74；临时数据库功能检查全部通过。当前仍属于 UI-2，视觉待用户评审，不进入 UI-3。
