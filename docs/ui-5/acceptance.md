# UI-5 背景与装备交付记录

状态：施工及功能验证完成。用户授权先完成 UI-5，前面各批次的视觉问题留待统一修改；UI-3/4/5 尚未获得视觉通过。未执行 UI-6、B7/B8。

## 改动

- 九个背景字段改为手记纸页，桌面两列、手机单列；个人经历使用全宽文本框。保留原有字段和文本存储，长文可滚动及拖动高度。
- 武器大表格改为可编辑档案卡。名称、类型、使用技能、伤害、射程、每轮攻击、装弹、故障和数量直接显示；贯穿、时代、价格、发明时间和备注收进详情。
- 军械目录使用真实文字数据，支持分类、名称/技能/时代搜索、无结果提示与连续加入；不放武器图片。
- 护甲、现金、物品及法术使用同一纸面样式；新增和删除保留原有数据行为，并即时更新空状态。
- 导出入口统一为纸面按钮“导出角色卡”；列表原有纸面导入弹窗继续复用。完整下载/上传流程实际验证。
- 沿用已交付纸框和黑玫瑰素材，本批未生图、未增加依赖，没有改动认证、规则、存储或 API。

## 文件

`web/gear.js`：服务端武器及物品/法术模板、军械目录。

`web/gear-ui.js`：搜索、分类、目录加入、自定义记录和空状态。运行新增记录直接克隆服务端模板，避免两套字段定义。

`web/gear.css`：手记、军械目录、装备卡和窄屏样式。

`web/pages.js`、`web/editor.js`、`web/static-assets.js`：页面装配、原保存流程复用及静态样式白名单。旧武器 select 和横向装备表格已移除。
